Indicator index

Status meanings:

Manual: updated by hand only.
Parallel run: automation exists, but the owner also keeps and updates a manual workbook.
Trusted: promoted after the criteria below. Only the owner changes this status.

Trust criteria (set before switching): the automated workbook matches the owner's manual one cell for cell for 3 consecutive months; the anomaly audit finds nothing new; and a validation failure produces a stop with an explanation, never a wrong number. Every difference during the trial is explained against the source, not just noted.
